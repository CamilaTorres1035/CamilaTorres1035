### Proyectos Destacados

* 🍯 **[HoneyMoney](https://github.com/CamilaTorres1035/honeymoney)**  
  API RESTful para la gestión de finanzas construida con **Spring Boot** y **Supabase**. Incluye autenticación con JWT (Access + Refresh tokens), filtros paginados, sanitización de respuestas de error y documentación interactiva en Swagger.

* ⏱️ **[RateLimiter](https://github.com/CamilaTorres1035/rate-limiter)**  
  Middleware de Rate Limiting ultraligero en **Java nativo** (sin frameworks). Aplica el algoritmo **Token Bucket** con evaluación perezosa, concurrencia *Thread-Safe* (`ReentrantLock`), soporte para proxies y pruebas de carga con **k6**.
